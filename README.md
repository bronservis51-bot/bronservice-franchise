# Франшиза «Бронь Сервис» — загрузка без папок

Все файлы в одной директории. GitHub Pages совместим с этой версией сайта без папки `assets`.

1. **Распакуйте** ZIP на компьютере.
2. В GitHub откройте нужный репозиторий → **Add file → Upload files**.
3. Выделите **все файлы** из распакованной папки и перетащите или выберите их для загрузки. Не загружайте ZIP вместо файлов.
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages → Build and deployment** → **Source: Deploy from a branch** → **Branch: main**, **Folder: / (root)** → **Save**.
6. Сайт будет доступен по адресу `https://USERNAME.github.io/REPOSITORY/` после завершения публикации.

Структура: `index.html`, 8 изображений (`*.webp`, `*.png`), `README.md`. Всё лежит на одном уровне. Не переименовывайте файлы.

Изображения для блока 03 встроены в галерею. Остальные разделы и WhatsApp-кнопки сохранены.
