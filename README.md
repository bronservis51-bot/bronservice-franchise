# Франшиза «Бронь Сервис» — отдельный сайт

Самостоятельный лендинг без зависимостей, Supabase, сборки и связи с корпоративным приложением.

## Как опубликовать на GitHub Pages (бесплатно)

1. Создайте **новый публичный репозиторий** с названием `bronservice-franchise` в нужном аккаунте GitHub.
2. Загрузите **содержимое** этого архива в корень репозитория (не вложенную папку) и сохраните изменения в ветку `main`.
3. Откройте `Settings` → `Pages` → `Build and deployment`, выберите источник **GitHub Actions**.
4. После выполнения workflow `Deploy independent franchise landing`, сайт будет доступен по адресу `https://<username>.github.io/bronservice-franchise/`.

Для аккаунта `bronservis51-bot` адрес будет `https://bronservis51-bot.github.io/bronservice-franchise/`.

## Фото в блоке 03 «Продукт»

Все пять предоставленных фотографий находятся в `assets/product-*.webp`. Для быстрой загрузки фотографии оптимизированы в WebP и подключены локально: сторонние сервисы и CDN не нужны. В разделе работают миниатюры, стрелки перелистывания и переключение видов покрытия.

## Лиды

Все кнопки «Купить франшизу» направляют на `wa.me/79956666614` с готовым сообщением. Посетитель **сам нажимает «Отправить»** в WhatsApp.

Номер и текст сообщения редактируются в `index.html`, в константах `waNumber` и `waMessage`.

## Что проверить перед запуском рекламы

- Условия, статистику точек и размер паушального взноса.
- Достаточность прав компании на используемый логотип.
- Работоспособность WhatsApp и приём лидов у исполнительного директора.
- Подключение собственного домена — отдельно и по желанию.

Не требует базы данных, рекламы, платных библиотек или сервисов для обработки кнопки WhatsApp.
