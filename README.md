# Франшиза «Бронь Сервис» — сайт

Сайт: https://bronservis51-bot.github.io/bronservice-franchise/

Один файл `index.html` и картинки рядом с ним. Сборки нет: GitHub Pages показывает файлы как есть (Settings → Pages → Branch: main, Folder: / (root)).

## Заявки

Кнопка «Купить франшизу» открывает анкету из 5 шагов: город и сроки, бюджет, кто будет на точке и опыт, место под островок, контакты. Сайт намеренно короткий: первый экран, «Почему это работает», «Деньги», «Поддержка» (обучение, место, закупка, после открытия) и «Знакомство». Каждый факт упоминается один раз — не дублируйте цифры и тезисы в разных блоках. Ответы уходят в кабинет франчайзи — раздел **«Заявки»** у менеджера по франшизе (https://bronservis51-bot.github.io/bron-franchise/). Там у каждой заявки оценка «горячая / тёплая / холодная», кнопки звонка и мессенджеров, статус и заметка.

Если отправка не прошла (нет интернета, сбой), анкета предлагает отправить те же ответы в WhatsApp +7 995 666-66-14.

## Цифры на сайте

Взяты из презентации «Бронь Сервис — франшиза» (октябрь 2026): 38 точек в 3 странах, с 2019 года, средний чек ≈2 000 ₽, вложения ≈1 млн ₽ с паушальным взносом 450 000 ₽, выручка точки 200 тыс – 1 млн ₽ в месяц, окупаемость 7–10 месяцев, роялти 7 %, островок 4–6 м², 30 дней до открытия. Если цифры изменятся — поправьте их в `index.html` (поиск по тексту).

## Для кого сайт (портрет клиента, октябрь 2026)

Тексты построены на портрете покупателя, а не на перечислении услуг.

- **Кто.** Человек из региона с бюджетом около 1 млн ₽ (собственные деньги или деньги семьи), часто без опыта в бизнесе. Три типа: уходит из найма; открывает дело для семьи; уже владеет точкой и хочет ещё одну (у двух партнёров уже по 3–4 точки).
- **Чего хочет (работа, которую «нанимают» франшизу делать):** «своё дело, которое не прогорит, даже если я раньше бизнес не вёл».
- **Чего боится:** потерять деньги, не справиться без опыта, купить «франшизу-пустышку», остаться одному после оплаты.
- **Как на это отвечает сайт:** первый экран — «свой бизнес» и «опыт не нужен»; блок «Деньги» честно отвечает, сколько вложить и когда вернётся; блок «Поддержка» отвечает на четыре главных вопроса: обучение, место, закупка, жизнь после открытия; финал — личное знакомство с директором вместо «продажи».
- **Источники:** данные кабинета франчайзи (города, число точек у партнёров), Businessmens.ru и TopFranchise (71 % заявок — франшизы до 1 млн ₽), Sostav/Franshiza-info (женщины — около половины интересующихся; мотивы: самореализация, уход из найма, семейный бизнес).
